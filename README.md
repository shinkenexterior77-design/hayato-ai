# HAYATO AI — iPhone向けWebアプリ試作版

## 今できること
- 近未来風の専用チャット画面
- テキスト入力と簡易ローカル応答
- ブラウザが対応している場合の日本語音声入力
- iPhoneの音声読み上げ機能による応答読み上げ
- PWA用manifest/service worker

## iPhoneで試す
1. このフォルダ一式をHTTPS対応のWebホスティングへ配置する。
2. iPhoneのSafariで公開URLを開く。
3. 共有ボタン →「ホーム画面に追加」。
4. ホーム画面のHAYATOを起動する。

ローカルファイルを直接開くだけではPWA機能やマイクが動かない場合があります。HTTPSで公開してください。
iOS Safariの音声認識対応はバージョンや環境で異なります。マイクが使えない場合は文字入力を利用してください。

## 本格AIを接続する
フロントエンドからOpenAI APIキーを直接呼び出さないでください。キーが漏えいします。
安全なサーバーに POST /api/chat を用意し、JSON { "message": "..." } を受け取り、
JSON { "reply": "..." } を返すようにしてください。
index.htmlは /api/chat を呼び出し、接続できない場合は試作用のローカル応答にフォールバックします。

この配布物はUI/操作の試作版です。Web検索、長期記憶、実際のAI推論、画像アップロードはまだ未接続です。
