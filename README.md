# HAYATO AI CORE v0.2
AIコア型キャラクターが自然に浮遊・発光し、音声読み上げ中に脈動します。話し方は「頼れる相棒」。読み上げと動きの切替が可能です。

## 更新方法
GitHubリポジトリのルートに index.html / manifest.webmanifest / sw.js をアップロードして既存ファイルを置き換え、コミットしてください。README.md の置換は任意です。数分後GitHub Pagesを再読み込みしてください。

## 注意
現在の応答はルールベースの試作版で、OpenAI APIやWeb検索は未接続です。iPhone Safariの音声入力は端末・OSによって利用できない場合があります。読み上げの声は端末依存で、男性声を保証しません。GitHub Pagesは静的ホスティングなので、AI APIキーをHTML/JSに書き込まないでください。AI接続には別途安全なバックエンドが必要です。
